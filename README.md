# 🚀 AI-Powered Sentiment Analysis System

## 📌 Overview
This project builds an end-to-end Machine Learning system that analyzes text sentiment and deploys it as a production-ready API using FastAPI and Docker.

---

## 🎯 Problem
Companies receive massive amounts of customer feedback but lack automated systems to extract sentiment insights efficiently.

---

## 💡 Solution
This system:
- Cleans and preprocesses text data
- Converts text into numerical features (TF-IDF)
- Trains ML models for classification
- Deploys a REST API for real-time predictions
- Containerizes the application using Docker

---

## 🧠 Models Used
- Logistic Regression
- Naive Bayes

---

## 📊 Results
| Model | Accuracy | F1 Score |
|------|---------|---------|
| Logistic Regression | 88% | 0.87 |
| Naive Bayes | 85% | 0.84 |
